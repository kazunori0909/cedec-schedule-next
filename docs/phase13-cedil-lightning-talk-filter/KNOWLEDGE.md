# Phase 13 で判明した挙動・制約

## CEDiL 検索結果一覧に「形式」が載っている

`https://cedil.cesa.or.jp/cedil_sessions/search_tag/{tag}` の各 `.session_list` は、
セッション詳細ページを開かなくても形式を持っている。

```html
<div class="name"><strong>形式 ： </strong>ライトニングトーク</div>
```

ラベルの表記は**一覧が `形式 ： `（全角コロン＋前後に半角スペース）、詳細ページが `形式：`** と
揺れる。判定時は空白とコロン種別を吸収すること（`/形式\s*[:：]\s*ライトニングトーク/`）。
JS の `\s` は全角スペース `　` にもマッチする。

2026 年度（tag=760）で確認できた形式の値:

- レギュラーセッション(60分) / ショートセッション(25分) / パネルディスカッション(60分)
- ワークショップ / ラウンドテーブル(60分) / **ライトニングトーク**

## ライトニングトークは公式タイムテーブルに存在しない

CEDiL に資料はあるが、公式の `session/timetable.json` には含まれない。
そのため `buildCedilLookup`（`src/lib/cedil.ts`）でどのセッションにもマッチせず、
`cedil.json` に残しても死にデータになる。

## 実機確認の結果（2026-07-23）

`npm run dev` + headless Chromium で `?year=2026` を 3 日分巡回:

| 日   | CEDiL 資料リンク数 |
| ---- | ------------------ |
| 7/22 | 9 件               |
| 7/23 | 2 件               |
| 7/24 | 0 件               |

ユニーク 11 件 = `cedil.json` の 11 件と完全一致（未表示 0 件）。コンソールエラーなし。
セル上は「資料公開: 公開済み」リンクとして表示される（未公開は「資料公開: 不明」）。

## 検証環境のメモ

このリポジトリには Playwright / chromium-cli が入っていない。ブラウザ確認が必要な場合は
リポジトリ外（スクラッチパッド）に `playwright-core` + `playwright install chromium` を
用意して driver スクリプトを書く。`package.json` は汚さない。
