# Phase 17: トークン設定の配置見直しと Excel の LT シート

## 課題

Phase 16 で「対象外」として持ち越した2件を扱う。

1. **CEDiL 更新トークンの設定ファイルがビルド成果物に混入する**
   `next build` は `public/` を丸ごと `out/` へコピーするため、`public/cgi/generate_cedil.config.php`
   をローカルに置いていると必ず `out/cgi/` に入る。XServer は PHP を実行するのでソースが平文で
   返ることはないが、次の2点が残る。
   - `out/` をそのままデプロイすると、**サーバー上の実トークンをローカルの値で上書きしてしまう**
     （ダミー値なら以後の URL/cron 実行が 403 になり、原因に気づきにくい）
   - 成果物・バックアップ・CI キャッシュに実トークンが載り、`.gitignore` の保護が効かない
   - SECURITY.md の「`public/` に機密情報を置かない」に反する
2. **Excel 出力にライトニングトーク（LT）が含まれない**
   Phase 14 で LT タブを追加したが、Excel は Day1〜3 のシートのみ。画面で見えるものが
   ダウンロードに含まれず、説明しづらい状態になっている。

## 方針

### 1. 設定ファイルを webroot の外から読む

`generate_cedil.php` の設定読み込みを「webroot 外を優先し、従来パスへフォールバック」にする。

```
1. <webroot の親>/cedil_config.php   ← 推奨（Web 公開されない・out/ にも入らない）
2. <webroot>/cgi/generate_cedil.config.php  ← 従来パス（後方互換。移行するまで動く）
```

どちらも見つからない・`key` が空の場合は URL 経由の呼び出しをすべて 403 にする現行の
fail-safe を維持する。

- 案A（採用）: 読み込み先の候補を増やす。サーバー側でファイルを1つ移すだけで済み、
  既存の設置を壊さない。
- 案B（不採用）: 環境変数（`.user.ini` / `SetEnv`）から読む。webroot 外に置くのと安全性は
  同等だが、XServer 側の設定手順が増えるうえ、cron の CLI 実行と Web 実行で環境変数の
  引き継ぎ方が変わるため運用が複雑になる。
- 案C（不採用）: 運用でカバー（ローカルに実ファイルを置かない・デプロイ時に除外）。
  手順を守り続ける前提になり、事故の芽が残る。

### 2. Excel に LT シートを追加

日ごとのシート出力処理を関数に切り出し、LT も同じ処理で1シート（シート名 `LT`）として出力する。
LT は全日程を横断するため日別シートには分けない。カラム見出しは画面と同じ `Day1-1` 形式。

時刻軸が5分刻みでなくても `buildMatrix` は行インデックスの差でセル高を決めるため、
LT の6分刻み・日ごとに異なる開催時間でもそのまま成立する。

## 決定事項ログ

### 2026-07-30: 設定の探索を「親ディレクトリを上へ辿る」方式へ変更

- 当初は `dirname(__DIR__, 2)`（＝スクリプトの2階層上）を「公開ディレクトリの親」と決め打ちしていたが、
  本番サイトは `public_html/cedec_schedule/` というサブディレクトリ配下にデプロイされており、
  2階層上は `public_html`（公開ディレクトリそのもの）だった。設定が見つからず 403 になった。
- 階層の深さに依存しないよう、スクリプトの親ディレクトリを上へ最大5階層辿って
  `cedil_config.php` を探す方式に変更。直下配置・サブディレクトリ配置のどちらでも、
  設定を公開ディレクトリの外に置ける。従来パスへのフォールバックは維持。
- サブディレクトリ配置・直下配置・設定なし（403）・CLI 実行の4パターンをローカルの
  PHP ビルトインサーバーで再現して確認した。

### 2026-07-30: サンプルもリポジトリルートへ移動

- 実値を webroot 外へ移しても、サンプル（`generate_cedil.config.sample.php`）が `public/cgi/` に
  残っていると `out/cgi/` へコピーされ Web 公開される。中身はプレースホルダーだが、
  エンドポイントが `?key=` を要求する仕組みを外部に知らせる必要のない情報になる。
- サンプルもリポジトリルートへ移し `cedil_config.sample.php` にリネームした。
  ローカルのリポジトリルートはサーバーの「公開ディレクトリの親」に対応するため、
  サンプルと実物が同じ階層に並び、設置手順を取り違えにくくなる。
  （実際、移行作業でサンプルと本体スクリプトの取り違えが起きたため、この配置を優先した）
- 結果、`out/cgi/` に入るのは `generate_cedil.php` だけになった。

### 2026-07-30: 3件の方針をユーザーが決定

- トークン設定は案A（webroot 外を優先して読む）を採用。
- Excel には LT シートを追加し、シート名は日別に分けず `LT` にまとめる。
- Phase 4（devcontainer で Fable 5 を選択可能に）は実機で選択できることを確認済みのためクローズ。
