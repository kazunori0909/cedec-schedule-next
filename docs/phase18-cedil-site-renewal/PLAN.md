# Phase 18: CEDiL サイトリニューアル対応

## 課題

CEDiL がリニューアルされ、年度別検索の URL とページの HTML 構造が変わった。

1. URL のパラメータが `search_tag/{id}`（パス）から `search?event={id}`（クエリ）になった
2. 一覧の HTML が全面的に置き換わり、旧セレクタ（`.session_list` / `h2` / `.page_change`）が
   1つも存在しない。`public/cgi/generate_cedil.php` の `parsePage()` は 0 件を返す
3. しかも旧 URL は新 URL へ 301 されるため取得自体は成功し、**空の `cedil.json` を
   `ok: true` で書き出す**（サイレント破損）。会期中に気づかず資料リンクが全消えする危険がある

## 方針

### ID は振り直さない

旧タグ番号と新イベントIDは**同一の値**。新サイトの年度プルダウン（`data-value`）と
`$YEAR_TAG` の全 16 年度が一致し、旧 URL も同じ ID の新 URL へ 301 される（KNOWLEDGE.md 参照）。
よって `SCHEDULE_SETTING.cedil_tag_no` / 年度テーブルの値は据え置き、URL の組み立てだけ変える。

### キー名 `cedil_tag_no` は変えない

「tag」は旧サイト由来の名前になるが、リネームすると型・フック・テスト・過去フェーズ記録まで
広く波及する割に、値も意味も変わらない。PHP 側の変数（`$YEAR_TAG` → `$YEAR_EVENT`）と
ドキュメントの呼称のみ「イベントID」に揃え、TypeScript のキー名は据え置いて由来を注記する。

### パーサーは新セレクタへ追従

| 用途           | 旧                                   | 新                                         |
| -------------- | ------------------------------------ | ------------------------------------------ |
| セッション一覧 | `.session_list`                      | `a.c-session-card`                         |
| タイトル       | `.session_list h2`                   | `.c-session-card__title`（`h3`）           |
| 詳細 URL       | `h2 a[href]`                         | `a.c-session-card` 自身の `href`           |
| 次ページ       | `.page_change` の `span.active` の次 | `a.c-pagination__arrow.--next` の `?page=` |

- 新 `href` には検索条件 `?event=760` が付く。**クエリを落として**詳細 URL だけを保存し、
  既存 `cedil.json`（`.../view/3274` 形式）との互換を保つ
- クラス名の部分一致（`c-session-card-list` を `c-session-card` として拾う）を避けるため、
  `cls()` は空白境界での照合を続ける。ヘルパーは「述語だけを返す」形に変え、
  `//a` などの要素指定と組み合わせられるようにした

出力 JSON の構造（`{ list: [{title, url}], update_date }`）は不変のため、アプリ側は無改修。

## 決定事項ログ

### 2026-08-28: イベントIDの再設定は不要と判断

新サイトの年度プルダウンと `$YEAR_TAG` の全 16 年度が一致、旧 URL も同一 ID へ 301 することを
実取得で確認した。ID 体系は変わっていないため、値の振り直しは行わない。

### 2026-08-28: 実データでの回帰確認をもって完了とする

PHP 側にユニットテストの仕組みがないため、旧パーサーの出力と新パーサーの出力を実データで
突き合わせて検証する（2014 年度＝リニューアル前に生成済みの `cedil.json` と完全一致すること）。
