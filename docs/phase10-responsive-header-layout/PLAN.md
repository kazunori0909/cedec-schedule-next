# Phase 10: レスポンシブ時のヘッダー最適化

## 課題

iPhone SE3（狭幅・375px）で表示した際、ヘッダー部分の高さが大きくなり、
タイムテーブル本体の表示領域を圧迫している。原因は主に次の2点。

1. **「Excel DL」のラベルが長い** — `ExcelDownloadButton` のボタン内テキストが
   ダウンロードアイコンと合わせて横幅を取り、ヘッダー右側が窮屈になっている。
2. **タイトルが折り返している** — `CEDEC {year} スケジュール`（[ScheduleView.tsx:88](../../src/components/ScheduleView.tsx#L88)）が
   狭幅で2行に折り返し、ヘッダーの高さが増している（画像では「CEDEC 2026 / スケジュール」の2行表示）。

## 方針

### 1. Excel DL の表現変更

- **条件分岐で PC/モバイルの表示を出し分けることはしない**（ユーザー方針）。
- 表現を変更する場合は、**PC のフルサイズ版も含めて「元々の表現」自体を変更する**
  （モバイルだけ別ラベルにするのは不可）。
- 対象は [ExcelDownloadButton.tsx:37](../../src/components/ExcelDownloadButton.tsx#L37) の
  ボタン内テキスト（現状 `Excel DL` / ローディング中 `生成中...`）。
  `title` 属性（`Excelとしてダウンロード`）はツールチップとして残す想定。
- **新しい表現は未決定**（決定事項ログで確定させる）。候補:
  - 案A: アイコンのみ（テキスト削除、`aria-label`/`title` でアクセシビリティ担保）
  - 案B: `Excel` のみに短縮
  - 案C: 別語（`DL` / `出力` 等）

### 2. タイトルの一行化

- 狭幅でも**改行させず**、フォントサイズを縮小して一行に収める。
- 現状 `text-xl font-bold`（[ScheduleView.tsx:88](../../src/components/ScheduleView.tsx#L88)）。
- レスポンシブなフォントサイズ指定で対応する想定（例: 狭幅は小さめ、`sm:` 以上で現行サイズ）。
  折り返し防止は `whitespace-nowrap` 等で担保する。
- CLAUDE.md の規約に従い、任意値（`text-[10px]` 等）は使わず `@theme` トークンを用いる。

## 決定事項ログ

### 2026-07-19: Excel DL の新表現 → 案A（アイコンのみ）

- ボタン内のテキスト（`Excel DL` / `生成中...`）を削除し、ダウンロードアイコンのみとする。
  PC フルサイズ版も同じ表現に統一する（モバイルのみの出し分けはしない）。
- 理由: 狭幅端末での横幅節約が最優先。ラベルを短縮しても幅を取るため、アイコン単独が最も効果的。
- アクセシビリティ: `title="Excelとしてダウンロード"` は維持し、`aria-label` を付与してテキスト削除を補う。
  ローディング中の視覚表現（現状 `生成中...`）はスピナー／アイコン差し替え等で別途担保する。
